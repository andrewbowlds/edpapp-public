# Contributing

This repository is a personal portfolio technical overview, not an open-source project accepting feature contributions — there's no application here to add features to.

That said, corrections are genuinely welcome:

- **Factual errors or unclear explanations**: if something in `docs/` is confusing, wrong, or you think I've overclaimed something, please open an issue. I'd rather this repo be accurate and a little unglamorous than polished and misleading.
- **Typos and broken links**: pull requests welcome, or just open an issue.
- **Security concerns**: see [`SECURITY.md`](SECURITY.md) — please don't open a public issue for anything that looks like it might be real (not fictional) data.

If you're a hiring manager or engineer who wants to talk through any of the architectural decisions in more depth than the docs cover, that's exactly what this repo is for — reach out using the contact info in the [README](README.md#links).
